# 🛡️ درع الغابة — منظومة إدارة حرائق الغابات

تطبيق ويب تقدّمي (PWA) لإدارة بلاغات حرائق الغابات في سوريا، مبني على:
- **Firebase Authentication** لتسجيل الدخول
- **Cloud Firestore** لتخزين البلاغات والسائقين والمستخدمين
- **Leaflet + OpenStreetMap** للخرائط
- **Service Worker** للعمل دون اتصال (PWA)

## هيكل المستودع

```
assets/
  icon-192.png          أيقونة التطبيق (192×192)
  icon-512.png          أيقونة التطبيق (512×512)
index.html              صفحة تسجيل الدخول / إنشاء حساب
observer.html           لوحة المراقب (رفع بلاغات + خريطة)
driver.html             لوحة السائق (المهام + تحديث الموقع)
ops.html                غرفة العمليات (إدارة البلاغات والتعيين)
manifest.json           ملف بيانات PWA
sw.js                   عامل الخدمة (تخزين مؤقت)
firebase-messaging-sw.js  إشعارات Firebase في الخلفية
```

## الصلاحيات

| الدور | الصفحة | الوصف |
|-------|--------|-------|
| `observer` | observer.html | مراقب: يبلّغ عن الحرائق من الخريطة |
| `crew` | driver.html | سائق/طاقم: يستلم المهام ويحدّث موقعه وحالة البلاغ |
| `admin` | ops.html | مدير عمليات: تعيين السائقين، إدارة المستخدمين |

الحساب الجديد يُنشأ بصلاحية `observer` تلقائياً، ويغيّر المدير الصلاحية من تبويب «المستخدمون».

## الإعداد

1. أنشئ مشروع Firebase وفعّل **Email/Password Authentication** و**Cloud Firestore**.
2. استبدل قيم `firebaseConfig` في الملفات بقيم مشروعك (أو اتركها إن كان المشروع جاهزاً).
3. في Firestore أنشئ مجموعات: `users`، `reports`، `drivers` وفعّل القواعد المناسبة.
4. ارفع الملفات إلى أي استضافة ثابتة (GitHub Pages / Firebase Hosting / Netlify).
5. استبدل الأيقونات في `assets/` بأيقوناتك الخاصة.

## ملاحظات

- المصادقة بالبريد وكلمة المرور فقط (6 أحرف كحد أدنى).
- مشاركة البلاغ عبر واتساب/رسائل نصية مدمجة.
- تحديد الموقع يتطلب HTTPS وإذن الموقع من المتصفح.
